# プライバシーポリシー

本アプリ「めもタス」（以下、「本アプリ」）は、ユーザーの個人情報を収集しません。  
ただし、広告配信のために第三者サービス（Google AdMob）を利用しています。

## 1. 収集する情報
本アプリ自体は、ユーザーの個人情報（氏名、メールアドレス、住所など）を一切収集しません。

ただし、広告配信のために Google AdMob が以下の情報を自動的に取得する場合があります。

- 広告識別子（AAID）
- 端末情報（OS、端末モデルなど）
- アプリの利用状況
- 広告の表示回数、クリック情報

これらの情報は匿名化されており、個人を特定するものではありません。

## 2. 利用目的
取得された情報は、以下の目的で利用されます。

- 広告の最適化
- 不正行為の防止
- 広告効果の測定

## 3. 第三者提供
本アプリは、広告配信のために Google AdMob を利用しています。  
Google のデータ利用ポリシーについては以下をご確認ください。

https://policies.google.com/technologies/ads

## 4. データの管理
本アプリはユーザーの個人情報をアプリ内で保存・管理しません。  
広告サービスによって収集されたデータは、Google のプライバシーポリシーに基づき管理されます。
